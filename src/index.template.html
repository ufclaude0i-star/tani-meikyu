あそびかた

このゲームでは、ボールは「数値」ではなく単位そのものを持ち歩きます。

1. ゴールは「単位を合わせる」こと

EXIT には必要な単位が書いてあります。そこにぴったり同じ単位で到達したときだけクリアです。単位が違うと、EXIT に立っても扉は開きません。

2. 道に浮かぶ単位の球を拾う

×kg÷s の球を通ると、手持ちの単位にその演算が起きます。手持ちが増えるほど自分の球は大きくなり、同じ単位で割ると相殺して小さくなります。すべて消せば無次元です。

3. 後戻りできない

一度通った道は崩れて穴になり、二度と通れません。分かれ道でどちらを選ぶかが、そのまま「どの演算を使うか」の決定になります。行き止まりに入ったら「もどす」か「やり直し」で戻れます。

4. 関門

🔒 は、書かれた条件（例：kg＝kgを持っている、¬m＝mを含まない、1＝無次元）を満たす手持ちでないと通れません。「どの順番で拾うか」が問われます。

5. 次元距離バー

EXIT の単位と、いまの単位がどれだけズレているかを表します。減る方向に進んでいれば正しい方向です。

なぜ単位で遊ぶのか

物理では、式を忘れても単位を組み立てれば答えの形が分かることがあります（次元解析）。「速さを出したいなら m/s だから、距離を時間で割ればいい」——この感覚が身につくと、公式の丸暗記から抜け出せます。
