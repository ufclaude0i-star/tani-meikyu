# 単位迷宮 — Dimension Labyrinth

物理の「単位」を掛けたり割ったりしながら迷路を抜ける、次元解析の学習ゲーム。
第7回 学力向上アプリコンテスト 応募作品（一般部門）。

## 動かし方

`dist/index.html` をダブルクリックするだけ。
インストール・ビルド・ネット接続はすべて不要です。
Windows / macOS / Linux の各ブラウザ、iPhone / iPad / Android のブラウザで動きます。

- PC: 矢印キー または WASD、マスのクリック、画面下のスティックをドラッグ
- スマホ / タブレット: 画面下のスティック、マスのタップ、スワイプ

## 遊び方（4行）

1. 主人公は半透明の球。中身は「物理の単位」で、持っている量だけ球が大きくなる。
2. 道に浮かぶ `×m` `÷s` の球を通ると、手持ちの単位がその演算を受ける。
   同じ単位で割ると **相殺** して球が小さくなる（音とエフェクトが出る）。
3. **後戻りできない。** 一度通った道は崩れて穴になる。分かれ道の選択がそのまま解答になる。
4. EXIT が要求する単位に **ぴったり一致した** ときだけ扉が開く。

関門（🔒）は、条件を満たす単位を持っているときしか通れません。
√ の橋は、すべての指数が偶数のときしか渡れません。
行き止まりや詰みに入ると自動で警告が出ます。「もどす」「やり直し」はいつでも使えます。

## ソースの構成

```
src/
  core.js             次元ベクトル演算・単位パーサ・表示・関門判定・最短手ソルバ
  render.js           3D描画エンジン（Canvas 2D に自前の透視投影。外部ライブラリなし）
  stages.js           全13ステージのデータ（迷路・単位・解説・クイズ）
  ui.js               画面制御（描画・入力・ヒント・クリア判定・セーブ）
  style.css           スタイル
  index.template.html HTMLのひな形
tools/
  build.js       src を1つのHTMLに結合して dist/index.html を作る
  gen.js         迷路生成器（ループ付き迷路を作り、正解ルート上に単位・関門を配置）
  specs.js       ステージ仕様（単位・演算の並び・解説・クイズ。教育的な中身は手書き）
  make-stages.js gen.js + specs.js から src/stages.js を生成（解けることを確認してから書き出す）
  verify.js      全ステージが本当に解けるか自動検証し、最短手数を出す
  e2e.js         実ブラウザ（Playwright）で13ステージ全部を自動クリアして回帰テスト
dist/
  index.html  提出用の単一ファイル（これ1つで完結）
```

ビルド:
```
node tools/make-stages.js  # ステージを生成（迷路のシードは固定なので毎回同じ）
node tools/build.js     # dist/index.html を生成
node tools/verify.js    # 全ステージの解の存在と最短手数を検証
node tools/e2e.js       # ブラウザで全ステージ自動プレイ（要 playwright）
```

## 設計上のポイント

- **迷路は自動生成、ただし出荷時は固定データ。** ループのある迷路（braided maze）を生成し、
  正解ルート上に必要な演算と関門を並べ、「後戻り禁止」ソルバで解けることを確認してから
  `src/stages.js` に書き出している。乱数のシードは固定なので、誰が実行しても同じ迷路になる。
- **一本道の迷路にはしていない。** 後戻り禁止＋一本道だと経路が一意に決まり、選択がなくなるため。
  わざとループを作り、複数のルートのうち一部だけが正解になるようにしている。
- **最短手数を人手で決めていない。** 自己非交差経路の探索器をゲーム内にも積んでおり、
  ステージを開いた瞬間に最短手数を計算して表示する。ステージを直しても評価がズレない。
- **詰みを自動検出する。** 1手ごとに「EXIT に到達可能か」「残っているマスで必要な単位を作れるか」を
  安く判定し、無理になった時点で知らせる。気づかないまま20手歩かせない。
- **ヒントは3段階。** ①ゴールとの差分 → ②残り最短手数 → ③次の一手。
  いきなり答えを出すと学習が消えるため、段階を踏ませている。
- **記憶モード。** 手持ちの単位表示をぼかし、頭の中で単位計算をさせる（想起練習）。
- **壁は辺（セルの境目）に立つ薄い板。** 迷路データは「セル＋壁のビット」で持ち、
  壁を全マス占有のブロックではなく境界の板として描くため、通路が広く、単位の球が大きく読める。
  床に落ちる影も自前で計算している（すべての影を1つのパスにまとめて1回で塗るので、重なっても濃くならない）。
- **外部ファイル・外部通信ゼロ。** 画像も音声ファイルも使わず、3D描画は Canvas 2D に自前の透視投影、
  効果音は WebAudio で合成している。Three.js などのライブラリも読み込まない。
- **盤面の自動回転。** 縦長の画面では迷路を90度回して配置し、画面いっぱいに表示する。
  操作は「画面で見えている向き」に合わせて自動変換されるので、プレイヤーは意識しなくてよい。
